# 项目出版版简介

## 项目名称

视觉风格分类与创意判断分析工具  
Visual Style Classification and Creative Judgement Analysis Tool

## 这是一个什么项目

这是一个围绕“机器如何判断视觉风格”的课程项目。

用户可以选择一张本地图像，系统会：

1. 判断它更接近哪一种视觉风格类别
2. 给出对应的置信度
3. 展示相近参考图作为辅助解释

这个项目的重点不是做图像检索，而是**分析机器如何进行审美判断**。

## 当前版本的核心思路

这个项目的重点是：

- 建立一个小型自定义视觉风格数据集
- 使用 CLIP 提取图像特征
- 使用轻量分类器做风格预测
- 分析错误案例和主观标签边界

## 当前独立数据集

这一版使用的是一个**自定义视觉风格分类数据集**，包含四个类别：

1. `neoclassical`
2. `industrial`
3. `organic`
4. `minimal`

这套数据与另一个检索项目完全分开，不共用图片。

## 当前能展示什么

当前初版已经可以展示：

1. 本地图像的风格预测
2. 分类置信度
3. 测试集评估结果
4. 混淆矩阵与误判分析思路

## 当前版本结果

当前 starter 版本已有一轮基础评估结果：

- Accuracy: `0.857`

这个结果足以支撑一个初版课程项目，同时也保留了后续反思空间。

## 这个项目适合作业的原因

它符合 EMI 作业要求，因为它同时具备：

1. 明确的机器学习任务
2. 和 creative practice 相关的批判性问题
3. 可运行的本地 demo
4. 可写 README、weblog 和视频展示
5. 对主观审美分类的反思空间

## 一句话总结

这是一个研究“机器如何把图像归入主观风格类别”的课程项目初版。
