# EMI Final Project Idea

## 项目名称

**视觉风格分类与创意判断分析工具**  
Visual Style Classification and Creative Judgement Analysis Tool

## 这个项目是干什么的

这个项目要做的是一个**研究机器如何判断视觉风格的小型分析工具**。

用户可以上传一张图片，系统会判断这张图片更接近哪一种视觉风格类别，并给出对应的判断结果和置信度。

简单理解，它不是一个“自动生成艺术作品”的工具，也不是一个重点做推荐的搜索系统，而是一个：

- 帮你测试图像会被机器归到哪一类
- 帮你观察机器的判断依据
- 帮你分析风格标签到底有多主观

的小型研究型创意工具。

## 它能做什么

这个项目完成后，大概会有下面这些功能：

1. 用户上传一张图片
2. 系统分析它更接近哪种风格类别
3. 系统给出预测结果和置信度
4. 系统辅助展示几张相近参考图
5. 用户可以据此分析模型为什么会这样判断

## 为什么这个题目适合作业

这个题目很适合 EMI 的最终大作业，因为它同时满足几件事：

1. **有明确的机器学习内容**  
   不是只用现成 AI 网页，而是自己准备数据、训练模型、做评估和展示。

2. **和 creative practice 有关系**  
   它讨论创作者如何看待视觉风格、审美标签和机器判断，而不是只做一个抽象分类器。

3. **最后成果比较直观**  
   可以展示输入图片、输出风格判断、置信度、错误案例和界面效果。

4. **容易加入反思**  
   这个项目也会讨论一个问题：  
   机器到底是在“理解风格”，还是只是在根据颜色、构图和内容做快捷判断？

## 项目的核心想法

这个作业不是想证明“机器可以客观定义艺术风格”，而是想探索：

**机器学习能不能把图像归入人为定义的风格类别，同时暴露它自己在审美判断上的局限。**

这也是这个项目最有意思的地方。

## 最后会交付什么

这个项目最后会形成一个完整的课程作业包，包括：

1. 一个公开 GitHub 项目仓库
2. 可运行的代码
3. 一个小型图像数据集和数据说明
4. 模型训练与评估结果
5. 一个可演示的网页小工具界面
6. README
7. weblog
8. 3 到 5 分钟的视频演示

## 项目最后看起来会像什么

最后展示时，老师或观众会看到的是这样一个流程：

1. 打开项目界面
2. 上传一张参考图或艺术图像
3. 系统输出风格类别和置信度
4. 展示分类结果与错误案例
5. 结合结果讨论模型判断得对不对、为什么会错、它说明了什么

## 一句话总结

这是一个把**机器学习、图像风格分类、审美判断分析和批判性反思**结合起来的课程项目。  
它既是一个小型创意分析工具，也是一个关于“机器如何理解审美”的实验。
