# 项目与作业要求对齐说明

这个项目对应课程要求的方式如下：

## 1. 机器学习技术实现

项目不是只调用现成网页工具，而是包含了完整代码路径：

1. 数据整理
2. 图像 embedding 提取
3. 分类器训练
4. 模型评估
5. demo 界面

## 2. creative practice 相关性

项目被定义为一个创作者工具，而不是普通分类作业：

1. 帮助整理 moodboard
2. 帮助分析视觉灵感
3. 帮助比较不同参考图之间的风格接近性

## 3. 课程中的机器学习核心主题

这个项目可以明确体现：

1. 数据选择与准备
2. 方法选择与配置
3. 使用预训练模型和轻量分类器建立系统
4. 用准确率、混淆矩阵和错误案例评估模型
5. 对风格标签主观性进行批判性讨论

## 4. 过程记录要求

仓库内已经包含：

1. `weblog.md`
2. 训练脚本
3. 评估脚本
4. confusion matrix
5. 测试集预测结果

这使得从代码到结果的路径比较清楚。

## 5. 视频展示要求

这个项目适合录制 3-5 分钟视频，因为可以很直接展示：

1. 数据集结构
2. 训练脚本运行
3. confusion matrix
4. Gradio demo 上传图片后的结果

## 6. 批判性思考空间

项目的核心批判点包括：

1. 风格标签是否本来就是主观的
2. 模型是否只是根据颜色、内容和构图做捷径判断
3. 机器学习是否会把复杂审美经验压缩成粗糙类别
4. 创作者是否会被机器标签反过来影响自己的判断
