# Demo Video Plan

Target length: 3-5 minutes

Suggested structure:

1. project title and one-sentence aim
2. show the dataset folders and explain the four style labels
3. show the training / evaluation commands or the finished report files
4. show the confusion matrix and explain one ambiguous boundary
5. launch the local desktop app with `python src/demo_app.py`
6. classify 2-3 example images in the desktop interface
7. close with one reflection on the subjectivity of style labels
